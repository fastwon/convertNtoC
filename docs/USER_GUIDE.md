# convertN2C 사용 설명서

소설을 회차별로 넣으면 **일관된 화풍·캐릭터**로 만화 컷을 만들어 주는 Windows 프로그램입니다.
모든 데이터는 **내 PC에만** 저장되고, 그림·글 생성은 **내 API 키**로 직접 호출됩니다(생성 단계에는 인터넷 필요).

> 앱 안에서도 상단 **도움말** 탭에서 같은 내용을 볼 수 있습니다.

---

## 1. 처음 한 번 — API 키 넣기

상단 **설정**에서 키를 입력합니다. 둘 중 **하나만** 있으면 시작할 수 있어요.

| | 키 | 발급처 | 설명 |
|---|---|---|---|
| 무료 | **Gemini** | `aistudio.google.com/apikey` | 설정에서 **“무료 버전 사용”**을 켜면 이 키로 동작. 품질은 낮지만 비용 없음. 분당 요청 한도 있음. |
| 유료 | **Anthropic(Claude)** | `console.anthropic.com` | 품질이 가장 좋음. 사용한 만큼 **본인에게 과금**. |

- 이미지: **Pollinations**(무료·키 불필요)가 기본, **Gemini 이미지**(유료)도 선택 가능.
- 키는 **Windows 자격증명 관리자**에만 저장되고 화면엔 가려서 표시됩니다. 저장 시 실제 호출로 유효성 검사.

---

## 2. 만화 만드는 순서

1. **프로젝트 만들기** — 대시보드에서 새 프로젝트 + 화풍 지정(예: “로맨스 판타지풍, 부드러운 채색”). 이 화풍이 모든 회차 기본값으로 고정됩니다.
2. **회차 본문 넣기** — 회차 탭에서 소설 본문 붙여넣고 저장.
3. **인물 추출 · 캐릭터 뱅크** — “인물 추출”로 등장인물을 뽑아 저장. 캐릭터 탭에서 인물별 외형·참조 이미지를 등록하면 일관성이 좋아집니다.
4. **콘티(컷) 생성** — 회차의 “콘티 생성”으로 장면을 컷으로 분할.
5. **컷 이미지 만들기** — 각 컷에서 **이미지 자동생성**(무료), 또는 **프롬프트 복사** → Gemini 웹에서 참조 이미지로 그린 뒤 **이미지 업로드**.
6. **대사 넣기** — 말풍선을 **드래그**해 위치를 정하고 “대사 합성”. 폰트·말풍선 스타일은 설정 탭에서 변경.
7. **모아 보기 · 내보내기** — “만화 보기”로 세로 스크롤 감상, 상단에서 **PNG / PDF / ZIP**으로 내보내기.

---

## 3. 비용과 저장 위치

- **비용**: 무료 모드(Gemini·Pollinations)는 **$0**. Claude 사용 시 프로젝트 **설정 탭 → 사용량·예상 비용**에서 대략적인 지출을 확인.
- **내 데이터**: `%LOCALAPPDATA%\convertN2C` (프로젝트·이미지·DB). 설정 → 스토리지에서 “폴더 열기”.
- **내보낸 만화**: `문서\convertN2C 내보내기` 폴더.

---

## 4. 문제 해결

| 증상 | 해결 |
|---|---|
| “인증 실패 / 키를 확인하세요” | 설정에서 키를 다시 입력(만료·오타). |
| “요청 한도 초과” | 잠시(1분+) 후 재시도. 무료 Gemini는 분당 한도가 있음. |
| “인터넷 연결 실패” | 생성 단계는 온라인 필요. 연결 확인. |
| 같은 인물이 매번 다르게 나옴 | 무료 그림(Pollinations)은 얼굴 일관성이 약함. 캐릭터 참조 이미지로 외형을 등록하거나, Gemini 웹에서 만들어 업로드. |

---

## 참고

- 앱 실행에는 Windows 11 기본 포함된 **Edge WebView2 런타임**이 필요합니다(대부분 이미 설치돼 있음).
- 인터넷은 **생성 단계**(Claude·이미지 API 호출)에만 필요하고, 그 외에는 오프라인으로도 열람·편집됩니다.
